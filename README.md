# Week 3 – Cybersecurity Practical Projects

## Overview
This repository contains my Week 3 Cybersecurity practical projects, focusing on PDF password recovery using different password-cracking tools in a controlled lab environment.

## Project Module 1: Password Cracking with John the Ripper (JTR)
- Extracted the PDF password hash.
- Used John the Ripper in Kali Linux.
- Performed a dictionary attack using the RockYou wordlist.
- Successfully recovered and verified the PDF password.

## Project Module 2: Password Cracking with Networkwalks Tools
- Used Networkwalks Hash Calculator to extract the PDF hash.
- Submitted the hash to Networkwalks Password Cracker.
- Used an additional wordlist after the initial attempt was unsuccessful.
- Successfully recovered and verified the PDF password.

## Tools and Technologies
- Kali Linux
- John the Ripper
- RockYou Wordlist
- Networkwalks Hash Calculator
- Networkwalks Password Cracker
- Oracle VirtualBox
